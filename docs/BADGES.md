## 🎨 Custom Badges

You can create custom badges using [Shields.io](https://shields.io/):

```markdown
![Custom Badge](https://img.shields.io/badge/YOUR_TEXT-YOUR_COLOR-YOUR_COLOR)
```

### Examples:
```markdown

```
